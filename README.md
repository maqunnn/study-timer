# 4 — 学習記録PWA

「教材・単語・AI・その他」を1タップで始め、終了後に「話す・書く・読む・聞く」を複数選択して保存する、インドネシア語学習時間の記録アプリです。記録はまず端末に保存し、設定したGoogle Apps Scriptへ送ります。App Store、Google Play、専用サーバー、外部ライブラリは不要です。

## 公開済みアプリ

- アプリ: <https://maqunnn.github.io/study-timer/>
- ソースと更新手順: <https://github.com/maqunnn/study-timer>
- 手元で全ファイルを確認する場合は、このフォルダの `public/` と `apps-script/` を使います。

## 初回セットアップ

### Google Sheetsを作る

1. [Google Sheets](https://sheets.google.com/)で空白のスプレッドシートを作成します。
2. 「ファイル」→「設定」でタイムゾーンを日本（東京）など普段使う地域に設定します。
3. 「拡張機能」→「Apps Script」を開きます。

### Apps Scriptを設定・公開する

1. `apps-script/Code.gs` の内容をApps Scriptの編集画面へ貼り付けて保存します。
2. `setup` を一度実行し、画面に従ってスプレッドシートへのアクセスを許可します。Raw Sessionsの見出しが作成されます。
3. 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」を選びます。
4. 実行するユーザーは「自分」、アクセスできるユーザーは「全員」にしてデプロイします。ログイン不要のPWAから受信するためです。
5. 表示された `/exec` URLをコピーします。
6. 「プロジェクトの設定」→「スクリプト プロパティ」で `API_TOKEN` を確認します。未作成の場合は `setup` を再実行してください。トークンは他人に共有しないでください。

### アプリへ接続する

1. [アプリを開く](https://maqunnn.github.io/study-timer/)、またはGitHub PagesにHTTPSで公開したPWAを開きます。
2. 画面上部の「4」をタップして設定を開きます。
3. `/exec` URLと `API_TOKEN` を入力し、「接続確認」を実行します。
4. iPhoneはSafariの共有ボタン→「ホーム画面に追加」、Androidはブラウザーのメニュー→「ホーム画面に追加」から追加します。初回だけオンラインで開くとオフライン用ファイルが保存されます。

公開中のApps Scriptはこの配布物と同じコードを使います。別のSheetsに接続する場合は、そのSheetsから開いたApps Scriptに同梱のコードを貼り、上記手順を行ってください。

## ローカル確認

ターミナルでこの `public/` をHTTPSまたはlocalhostから配信してください（localhostならService Workerを使えます）。例: `npx http-server public -p 4173`。初回表示、画面を閉じたあとの復元、技能の複数選択、オフライン中の未送信表示を確認できます。Apps Script接続には公開URLとトークンの設定が別途必要です。

ロジックのテストは `npm test` で実行します。

## 毎日の操作

「教材/単語/AI/その他」をタップして開始 → 学習 →「終了」→ 技能を選ぶ（技能なしでも可）→「保存」です。記録は終了操作時に端末へ確定します。通信できない記録は端末に残り、オンライン復帰時に再送します。

FOCUSは本人が切り替える記録用スイッチです。iPhoneがロック中か、別アプリを使っているかをPWAが判定する機能ではありません。

## 動作上の注意

- 時間は秒ごとに加算せず、開始・一時停止・再開の時刻から復元します。Safariを閉じたり端末がスリープしても、次回起動時に継続時間を再計算します。
- 一時停止を忘れた時間や、端末時計を変更した影響は自動判定できません。計測中は一時停止を使ってください。
- PWAはRDBMSではないGoogle Sheetsを利用します。再送時の重複は `session_id` とApps Scriptのロックで抑止します。
- 端末のサイトデータを消去すると未送信データも消える場合があります。設定画面から定期的にJSONバックアップを保存してください。
- 画面はブラウザーの安全領域・タッチ操作に合わせていますが、物理iPhone全機種での実機試験は行っていません。

Rawの列と分析シートの計算方法は [DATA_MODEL.md](./DATA_MODEL.md) を参照してください。
