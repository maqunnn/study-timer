# Belajar — 学習時間記録PWA

「教材・単語・AI・その他」を1タップで始め、終了後に「話す・書く・読む・聞く」を複数選択して保存する、インドネシア語学習時間の記録アプリです。アプリ名は「Belajar」です。記録はまず端末に保存し、設定したGoogle Apps Scriptへ送ります。App Store、Google Play、専用サーバー、外部ライブラリは不要です。

## 公開済みアプリ

- アプリ: <https://maqunnn.github.io/study-timer/>
- 表示が古い場合の更新ページ: <https://maqunnn.github.io/study-timer/refresh.html>（端末内ログは残し、アプリ画面のキャッシュだけ更新します）
- ソースと更新手順: <https://github.com/maqunnn/study-timer>
- 手元で全ファイルを確認する場合は、このリポジトリ内のアプリファイルと `Code.gs` を使います。

## 初回セットアップ

### Google Sheetsを作る

1. [Google Sheets](https://sheets.google.com/)で空白のスプレッドシートを作成します。
2. 「ファイル」→「設定」でタイムゾーンを日本（東京）など普段使う地域に設定します。
3. 「拡張機能」→「Apps Script」を開きます。

### Apps Scriptを設定・公開する

1. `Code.gs` の内容をApps Scriptの編集画面へ貼り付けて保存します。
2. `setup` を一度実行し、画面に従ってスプレッドシートへのアクセスを許可します。「Raw Sessions」シートと必要な見出しだけが作られます。旧版が作った分析タブ（Daily、Weekly、Summaryなど）はこのとき削除されます。既存ログは残ります。
3. 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」を選びます。
4. 実行するユーザーは「自分」、アクセスできるユーザーは「全員」にしてデプロイします。ログイン不要のPWAから受信するためです。
5. 表示された `/exec` URLをコピーします。
6. 「プロジェクトの設定」→「スクリプト プロパティ」で `API_TOKEN` を確認します。未作成の場合は `setup` を再実行してください。トークンは他人に共有しないでください。

### アプリへ接続する

1. [アプリを開く](https://maqunnn.github.io/study-timer/)、またはGitHub PagesにHTTPSで公開したPWAを開きます。
2. ホーム画面右上の「設定」を開きます。
3. `/exec` URLと `API_TOKEN` を入力し、「接続して設定を保存」を押します。接続できない場合は、Apps Scriptのデプロイが「ウェブアプリ」「次のユーザーとして実行: 自分」「アクセスできるユーザー: 全員」になっているか確認してください。
4. iPhoneはSafariの共有ボタン→「ホーム画面に追加」、Androidはブラウザーのメニュー→「ホーム画面に追加」から追加します。初回だけオンラインで開くとオフライン用ファイルが保存されます。

今回のコードへ更新するときは、Apps Scriptに `Code.gs` を貼り付けて保存し、`setup` をもう一度実行してから、「デプロイ」→「デプロイを管理」→既存デプロイの鉛筆→「バージョン: 新バージョン」→「デプロイ」を選びます。 `/exec` が404になる場合は、既存URLが無効なため「新しいデプロイ」を作成し、新しい `/exec` URLをアプリの設定に入れてください。URLとAPI_TOKENを変更した後は、同画面の「未送信の記録を再送」を押します。別のSheetsに接続する場合も、そのSheetsからApps Scriptを開き、同じ手順を行ってください。

## ローカル確認

このリポジトリのファイルをlocalhostから配信してください（Service Workerを使うにはlocalhostまたはHTTPSが必要です）。例: `python3 -m http.server 4173`。初回表示、画面を閉じたあとの復元、技能の複数選択、オフライン中の未送信表示を確認できます。Apps Script接続には公開URLとトークンの設定が別途必要です。

ロジックのテストは `npm test` で実行します。

## 毎日の操作

「教材/単語/AI/その他」のどれかをタップするとすぐ計測が始まります。学習を終えるときは「終了」を押し、技能を選んで「保存する」を押します。技能は複数選択でき、選ばずに保存することもできます。計測中は秒まで進む時間と青い印の「計測中」、一時停止中は止まった時間と灰色の印の「一時停止中」が表示されます。記録は終了時に端末へ保存され、通信できない場合はオンライン復帰時に自動で再送します。

FOCUS ONの間は、集中していた時間として別に記録します。iPhoneがロック中か、別アプリを使っているかをPWAが自動判定する機能ではありません。勉強中にスマホを閉じるなど、ご自身の基準で切り替えてください。

## まず試す

1. [アプリを開く](https://maqunnn.github.io/study-timer/)。「教材」などを1つ押すと計測が始まります。
2. 秒表示が進むことを確認し、「一時停止」→「再開」を試します。画面を閉じて戻っても、計測中の時間が復元されます。
3. 「終了」を押すと、学習方法と時間を確認できます。「技能」から「話す」「聞く」などを選んで「保存する」を押します。複数選択や、技能を選ばない保存もできます。
4. 保存した記録はGoogle Sheetsの「Raw Sessions」に1行追加され、ホーム画面の今日の合計に反映されます。

最初の試用記録も通常の学習ログとして保存されます。あとで区別できるよう、短いテスト時間にして保存時刻を控えてください。試用ログが不要なら、「Raw Sessions」でその時刻の行を確認して削除できます。端末ごとに初回だけ接続設定が必要です。

## 動作上の注意

- 時間は秒ごとに加算せず、開始・一時停止・再開の時刻から復元します。Safariを閉じたり端末がスリープしても、次回起動時に継続時間を再計算します。
- 一時停止を忘れた時間や、端末時計を変更した影響は自動判定できません。計測中は一時停止を使ってください。
- PWAはRDBMSではないGoogle Sheetsを利用します。再送時の重複は `session_id` とApps Scriptのロックで抑止します。
- 端末のサイトデータを消去すると未送信データも消える場合があります。設定画面から定期的にJSONバックアップを保存してください。
- 画面はブラウザーの安全領域・タッチ操作に合わせていますが、物理iPhone全機種での実機試験は行っていません。
- 表示が古いままの場合は、上の更新ページを1度開いてください。アプリ表示だけを更新し、未送信記録は維持します。

保存する列は [DATA_MODEL.md](./DATA_MODEL.md) にまとめています。Sheetsには分析タブを追加せず、記録用の「Raw Sessions」だけを作ります。ロジックのテストは `npm test` で実行できます。
